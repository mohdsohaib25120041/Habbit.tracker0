# 🚀 GoalForce - Habit Tracker & Productivity App

GoalForce ek modern habit tracker aur productivity web app hai. Iska maqsad users ko unke daily goals, habits, aur tasks track karne mein madad karna hai.

## ✨ Features
- Habit & Task Tracking
- XP, Levels, aur Streaks (Gamification)
- Notes & Water Tracker
- Cloud Sync (Supabase)
- Admin Panel for User Management
- Mobile Friendly (PWA & Android App ready)

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend/Database: Supabase
- Hosting: GitHub Pages
